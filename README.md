# NIMEX D2D Operation Report

หน้าเว็บ Dashboard การเข้ารับสินค้า D2D ที่อ่านข้อมูลจาก Google Sheet ผ่าน Apps Script

- ข้อมูลทั้งหมดอยู่ใน Google Sheet ไม่มีตัวเลขใน repo นี้ ห้ามนำ `seed.json` หรือรายงาน Excel ต้นฉบับขึ้น repo
- repo นี้เป็นสาธารณะ ใครที่มีลิงก์หน้าเว็บจะเห็นข้อมูลที่หน้าเว็บแสดง
- ผู้ชมทั่วไปเปิดหน้าเว็บตามปกติ ผู้ดูแลเปิดด้วย `#admin` ต่อท้ายลิงก์แล้วใส่รหัส
- รหัสผู้ดูแลเก็บใน Script Properties ชื่อ `ADMIN_KEY` ของ Apps Script เท่านั้น
- ที่อยู่ระบบข้อมูลตั้งไว้ใน `config.js` (เพิ่มเลข `NIMEX_V` ทุกครั้งที่แก้ไฟล์ เพื่อล้างแคช)

## ตั้งค่าครั้งแรก

1. สร้าง Google Sheet ใหม่ › ส่วนขยาย › Apps Script › วางโค้ดจาก `Code.gs.txt` › บันทึก
2. ตั้งค่าโปรเจกต์ › Script Properties › เพิ่ม `ADMIN_KEY` = รหัสผู้ดูแล
3. ทำให้ใช้งานได้ › การทำให้ใช้งานได้รายการใหม่ › เว็บแอป › เรียกใช้ในฐานะ: ฉัน · ผู้ที่มีสิทธิ์เข้าถึง: ทุกคน › คัดลอก URL ที่ลงท้าย `/exec`
4. ใส่ URL ใน `config.js` ที่ `NIMEX_API` แล้ว Commit
5. Settings › Pages › Branch: `main` / `(root)` › Save
6. เปิดหน้าเว็บด้วย `#admin` ใส่รหัส แล้วเลือกไฟล์ `seed.json` (หรือรายงาน Excel) เพื่อนำเข้าข้อมูลครั้งแรก

## เติมข้อมูล

เปิด `#admin` › อัปโหลดรายงาน "NIMEX ... รายงานระบบ Booking และเข้ารับ" (ทุก DC ต้นทาง) › ตรวจผลสรุป › บันทึก
บิลที่สร้างในวันเดียวกับข้อมูลเดิมจะถูกลบแล้วใช้ค่าใหม่ จึงอัปโหลดไฟล์เดิมซ้ำได้โดยไม่เกิดข้อมูลซ้ำ
